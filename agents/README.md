# Agents

Agents are role-based assistants with a clear purpose, responsibilities, operating process, and boundaries.

Give each agent its own folder and begin with [`../templates/AGENT.template.md`](../templates/AGENT.template.md).

Keep agents narrow enough to evaluate. If an agent tries to research, design, write, code, and approve its own work, split those responsibilities.


## Available

- [`persona-reviewer`](persona-reviewer/AGENT.md): reviews a design as one specific user from a persona file. Pair with the `design-crit` skill.
