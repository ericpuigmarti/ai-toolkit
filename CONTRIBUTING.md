# Contributing

This is currently a personal toolkit, but suggestions and improvements are welcome.

## Principles

- Prefer a small, tested addition over a large collection of variations.
- Explain the reasoning behind important instructions.
- Use examples that are realistic but contain no confidential information.
- Document failures and limitations alongside successful results.
- Never commit credentials, customer data, or proprietary material.

## Naming

Use lowercase, descriptive, hyphen-separated names:

```text
design-critique
research-synthesis
concept-to-prototype
```

## Before publishing

- Remove secrets and personal data.
- Check that links and examples work.
- Add or update an evaluation when behavior changes.
- Update the changelog for meaningful additions.
