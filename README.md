# AI Toolkit

A curated collection of the skills, agents, prompts, workflows, and evaluations I use to design and build with AI.

This repository is a portfolio of working methods—not a dump of raw prompts. Each item should explain the problem it solves, how to use it, and what happened when it was tested.

## Repository map

| Folder | What belongs here |
| --- | --- |
| [`skills/`](skills/) | Reusable capabilities with instructions, examples, and references |
| [`agents/`](agents/) | Role-based assistants with defined responsibilities and boundaries |
| [`prompts/`](prompts/) | Focused prompts grouped by discipline |
| [`workflows/`](workflows/) | Multi-step processes that combine tools, prompts, or agents |
| [`templates/`](templates/) | Starting points for documenting new additions |
| [`evaluations/`](evaluations/) | Test cases, scorecards, and lessons learned |

## Quality bar

Before publishing an item, make sure it includes:

- The problem it solves
- When to use it—and when not to
- Required inputs and expected outputs
- A realistic example
- Known limitations
- Evidence or notes from testing

## Adding something new

1. Start with the closest file in [`templates/`](templates/).
2. Create a descriptive, lowercase folder using hyphens, such as `design-crit`.
3. Add a small example with any sensitive information removed.
4. Record meaningful changes in [`CHANGELOG.md`](CHANGELOG.md).

## Current status

This toolkit is being assembled in public. Early entries may change as they are tested and refined.
